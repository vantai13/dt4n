## Permanent control

`python -m tools.check_phase_g_custody` now checks the local backup basis
and live origin tag custody. It fails if any Phase G tag referenced in
`docs/phase-G/*.md` is missing locally/remotely or differs in tag-object ID.
Unavailable origin and empty documentation scans also fail the tag check.
Annotated tags compare their actual object IDs, not merely peeled commit IDs.

`--tags-only` checks remote references without assuming access to this host's
backup paths; it is suitable for a clean clone. `--local-only` explicitly
performs the historical offline backup check and makes no remote-custody claim.
The `evaluate()` Python API remains the existing offline backup evaluator;
call `check_remote_tags()` as well, or use the default CLI, for the full check.
Tag availability is not a substitute for `verify_protected()` or data hashes.
